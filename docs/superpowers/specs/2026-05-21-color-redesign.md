# 配色方案重新设计 — 暮光幻紫

**日期**: 2026-05-21
**范围**: 全局 CSS 变量替换

## 背景

网站当前配色为「蓝紫冷调」(cyan + purple)，用户认为过于单一，希望更换为更具电竞潮流感的暖调配色。

## 设计方向

选定「暮光幻紫」— 粉桃 + 薰衣草紫，温暖潮流，有日落渐变的视觉质感。

## 新 CSS 变量

| 变量 | 旧值 | 新值 | 说明 |
|---|---|---|---|
| `--bg-dark` | `#06060a` | `#0a0812` | 深紫黑底 |
| `--bg-card` | `#0d0d15` | `#141025` | 卡片背景 |
| `--accent` | `#00e5ff` | `#ff6b9d` | 主强调色 (粉桃) |
| `--accent2` | `#7c4dff` | `#c44dff` | 辅色 (薰衣草紫) |
| `--gold` | `#ffd740` | `#ffb347` | 暖金 |
| `--text-muted` | `#888` | `#8a8099` | 次级文字 |

`--text`, `--border` 保持不变。

## 实现方式

替换 [index.html](../../index.html) `:root` 块中的 CSS 变量值。所有使用 `var()` 引用的元素自动继承新配色，无需修改 HTML 结构。

## 影响范围

- 导航栏 logo 渐变色
- 标题渐变色
- 按钮渐变
- Canvas 粒子颜色
- 卡片边框高亮
- 所有 accent/accent2 引用
